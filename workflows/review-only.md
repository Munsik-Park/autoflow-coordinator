# review-only: AutoFlow for review only

## Goal

Review a change made outside AutoFlow (a document change, a small change, an existing PR) with the `review` module, so that it meets the quality goal.

## Groups and sessions

| Step | How | Goal of the step |
|---|---|---|
| Work and PR | A work session outside AutoFlow or a person (skipped if the PR already exists) | Make the requested change into a PR |
| Review | The `review` module, in a new session | Review the PR |

## Default quality goal

No finding that holds is Medium or above.

## Final result

The verdict and findings, condensed from the review report and posted on the PR without local paths, run commands or the text of the instructions.

## What to look for in the workspace's `coordination.md`

PR rules, the repository's review goal, the reviewers a review runs and the command that starts each, whether and how much of the report to post.
